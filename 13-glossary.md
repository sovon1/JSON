# 13 - Glossary

## API

An interface through which software systems communicate. JSON is commonly used for API request and response bodies.

## Array

An ordered list of JSON values surrounded by `[ ]`.

## Contract

An agreement about what shape data will have and what it means.

## Deserialization

Turning JSON text into runtime data structures. Often called parsing.

## JSON

A text format for structured data using objects, arrays, strings, numbers, booleans, and `null`.

## JSON Lines

A line-oriented format where each line is a valid JSON object. Common for logs and pipelines. Often stored as `.jsonl`.

## JSON Patch

A patch format based on explicit operations such as add, remove, and replace.

## JSON Schema

A vocabulary for describing what JSON is allowed to look like.

## Merge Patch

A patch style that describes partial changes by example.

## Null

An explicit empty value in JSON. It is different from a missing field.

## Object

A collection of key-value pairs surrounded by `{ }`.

## Parse

To convert JSON text into a runtime data structure.

## Payload

The actual data carried inside a request, response, event, or message.

## Schema

A formal description of allowed structure and constraints.

## Serialize

To convert runtime data into JSON text.

## Validation

Checking whether JSON matches expected rules.
